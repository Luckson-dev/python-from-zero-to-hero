
# Introduction à la programmation avec Python

## 💻 C’est quoi la programmation ?

La programmation est le fait de donner des instructions à un ordinateur pour qu’il exécute des tâches précises.

Un ordinateur ne comprend pas le langage humain. Il comprend uniquement des instructions écrites dans un langage de programmation.

👉 Un programme est donc une suite d’instructions exécutées étape par étape.


## C’est quoi un langage de programmation ?

Un langage de programmation est un langage intermédiaire entre l’humain et la machine.

Il permet de traduire nos idées en instructions compréhensibles par l’ordinateur.

Exemples de langages :
- Python 🐍
- JavaScript
- Java
- C / C++


## 🐍 Pourquoi Python ?

Python est l’un des meilleurs langages pour débuter car :

- Sa syntaxe est simple et lisible
- Il ressemble à de l’anglais
- Il est utilisé dans beaucoup de domaines :
  - développement web
  - intelligence artificielle
  - data science
  - automatisation


## Comment un programme fonctionne ?

Un programme Python est exécuté ligne par ligne.

Chaque ligne est une instruction.

Exemple :

```python id="print001"
print("Bonjour le monde")
````

👉 Ici, on demande à l’ordinateur d’afficher un message.


## Notions importantes à comprendre

Avant de coder, il faut comprendre quelques idées clés :

* Un programme est exécuté de haut en bas
* L’ordinateur suit des instructions précises
* Une erreur dans le code empêche l’exécution
* La logique est plus importante que la mémoire
