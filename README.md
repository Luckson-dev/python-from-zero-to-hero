
# 🐍 Python from zero to Hero

Bienvenue dans ce dépôt d’apprentissage de Python.

Ce projet est un parcours structuré pour apprendre la programmation avec Python, depuis zéro jusqu’à un niveau avancé. L’objectif est de progresser étape par étape, avec de la pratique, des explications simples et des projets concrets.


## Objectif du projet

Ce dépôt a pour but de t’aider à :

- Comprendre les bases de la programmation
- Maîtriser la syntaxe Python
- Développer une logique algorithmique solide
- Construire des projets concrets
- Passer de débutant à développeur autonome (0 → Hero)


## Installation des outils

### 1. Installer Python

Télécharge Python ici :  
https://www.python.org/downloads/

⚠️ Important :
- Sur Windows, coche **"Add Python to PATH"** pendant l’installation

Vérifie l’installation :

```bash
python --version
````

### 2. Installer VS Code

Télécharge Visual Studio Code ici :
[https://code.visualstudio.com/](https://code.visualstudio.com/)

Extensions recommandées :

* Python (Microsoft)
* Pylance
* IntelliCode

Comment utiliser ce dépôt

```bash
git clone https://github.com/ton-compte/python-from-zero-to-hero.git

cd python-from-zero-to-hero

code .
```

Ensuite, suis les dossiers dans l’ordre :

```
00-introduction → 01-bases → 02-syntaxe → ...
```
